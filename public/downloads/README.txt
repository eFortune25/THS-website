INSTRUCTIONS FOR PDF CONVERSION
================================

STEP 1: Create the PDF
-----------------------
1. Copy the content from "blog-content-for-pdf.txt" (in this same folder)
2. Paste it into a Word document or Google Doc
3. Format it nicely:
   - Add proper headers and footers
   - Include THS branding/logo
   - Format headings appropriately
   - Add page numbers
   - Ensure proper spacing and readability
4. Save/Export as PDF with the filename: "public-health-research-existing-data.pdf"

STEP 2: Upload the PDF
-----------------------
1. Save the PDF file to this folder: public\downloads\
2. The file should be named: "public-health-research-existing-data.pdf"

STEP 3: Build and Deploy
-------------------------
After uploading the PDF, the website will be rebuilt and deployed automatically.
The blog post has been updated to include a download button linking to this PDF.

The PDF will be accessible at:
https://t-healthsolutions.com/downloads/public-health-research-existing-data.pdf
